# Auth System

A frontend authentication system built with modern JavaScript, featuring real-time form validation and interactive modal feedback for a seamless user experience.


## Features

* **Form Validation:** Real-time checking for required fields, correct email formats, and secure password matching.
* **Modal Feedback:** Dynamic popup modals to notify users of successful login/signup or error states instead of standard alert boxes.
* **Responsive Design:** Clean and mobile-friendly UI styling.
* **Client-Side State Management:** Handles user sessions and input states cleanly using vanilla JavaScript.



##  Tech Stack

* **HTML5** for structure and markup
* **CSS3** (with modern styling / Tailwind / custom CSS) for layout and design
* **JavaScript (ES6+)** for DOM manipulation, event handling, and form validation logic
